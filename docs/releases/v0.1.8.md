# QuotaMonitor v0.1.8

- 添加账号使用官方网页登录，完成后自动接收并加密保存 token，立即刷新额度。
- 不再检测或读取本机其他软件的 auth.json；删除文件绑定入口。仍支持主动粘贴已有 token。
- 登录使用 PKCE、本机回调与 state/nonce 校验；保存 refresh token 并自动续期。
- 默认直接查询额度，不启动或内嵌 Codex App Server，不下载插件、模型或工具组件。
- 升级自动清理 QuotaMonitor 数据目录中的旧运行组件、插件、缓存、临时文件和日志，只保留账号凭据与必要设置、待核对记录。
- Windows 自动迁移本工具旧账号的加密凭据及系统凭据库登录，继续查询额度；现有新 token 优先保留，迁移失败时保留原凭据。
- 未登录或查询失败时，悬浮窗明确显示“请登录”或“失败”；可在账号详情查看原因和重新网页登录。

升级前退出旧版，使用新 EXE。只有旧登录已失效或系统密钥不可用时，才需要在账号详情重新网页登录。
