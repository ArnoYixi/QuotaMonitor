# QuotaMonitor v0.1.7

- 默认直接使用已有 token 查询额度，不再下载、内嵌或启动整套 Codex 组件。
- 添加账号支持读取本机 auth.json、绑定其他登录文件、粘贴 access token 或 token JSON。绑定文件更新后会自动读取新 token；不写回原登录文件。
- Windows 下粘贴的 token 使用当前用户 DPAPI 加密保存。
- 升级时自动删除 QuotaMonitor 数据目录内的旧运行组件、插件、缓存、临时文件及日志，保留必要凭据、设置和待核对重置记录。已绑定的 token 文件受到保护。
- token 模式只查询额度、积分和重置卡数量，不消耗重置卡。旧登录方式保留在设置的兼容选项中，需要手动指定已安装的 Codex。

升级前从托盘退出旧版，再运行新 EXE。旧版只存在系统凭据库中的登录需要在账号详情重新绑定 token，原加密凭据会保留。
