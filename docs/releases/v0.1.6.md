# QuotaMonitor v0.1.6

首个使用 **QuotaMonitor** 名称发布的版本。

## 更新内容

- 项目、可执行文件、托盘与构建产物统一使用 QuotaMonitor。
- 兼容旧版 QuotaMonitori 的账号与设置目录；已有开机启动项更新为新程序路径。
- 修复锁定或隐藏后托盘菜单无法操作、无法退出的问题。
- 托盘指令与后台状态由事件循环处理，解锁立即生效，无需隐藏再显示。
- 积分统一向上取整，不保留小数。
- 移除横条和圆环的黑色描边。
- 重写面向用户和贡献者的说明，增加实际截图与多种布局参考图。

## 下载与升级

下载 `QuotaMonitor-v0.1.6-windows-x64.zip`，解压后运行 `QuotaMonitor.exe`。升级前请从托盘退出旧版，避免同时运行两个版本。

发布包含程序、`Demo.bat`、使用说明及第三方许可证，内置已校验的官方 Codex 0.162.1 组件，无需另装 Python、Node.js 或 Codex CLI。

下载后可用 `SHA256SUMS.txt` 校验文件。Windows 10 / 11 x64，需要支持 OpenGL 的图形驱动；程序尚未进行代码签名。

本次提供 Windows x64 发布包。Linux 用户可从源码构建，窗口与托盘能力取决于桌面环境。本项目为社区独立开发，与 OpenAI 无隶属或背书关系。
